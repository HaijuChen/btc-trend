# BTC 多空判讀

手機打開就能看的比特幣趨勢頁。它用公開行情計算均線、MACD、RSI、ADX、布林通道與量能，把週線、日線、四小時合成一個看得到理由的分數，判定目前是強烈多頭、偏多、中性、偏空或強烈空頭。

這不是投資建議，也不是買賣訊號。頁面另有一塊四小時長線策略的參考信號，算法見下方，同樣不是下單、也不是投資建議。

## 本地執行

需要 Node.js 22 以上。

```bash
npm install
npm run dev
```

開發伺服器會開在 [http://127.0.0.1:4179](http://127.0.0.1:4179)。

```bash
npm run check         # 指標與分數的自我檢查
npm run build         # 產出 dist/，適合放上靜態空間
npm run build:single  # 產出 dist-single/btc-trend.html，單一檔案
npm run preview       # 預覽打包結果，同樣使用 4179
```

頁面每 60 秒重算一次指標，報價若連得上幣安的公開 WebSocket 會即時跳動。時間一律顯示台北時間。

## 部署

正式站：https://haijuchen.github.io/btc-trend/

這是純靜態網站，沒有後端、沒有金鑰。

```bash
npm run build
```

把 `dist/` 放到任何靜態空間即可，例如 Cloudflare Pages、Netlify、Vercel 或 GitHub Pages。建置指令是 `npm run build`，輸出目錄是 `dist`。資源路徑是相對的（`base: './'`），所以放在網域根目錄或任一子路徑都能開。

若要一個不用伺服器的檔案，執行 `npm run build:single`。它會把 JavaScript、CSS 和圖示都嵌進 `dist-single/btc-trend.html`。用手機瀏覽器直接打開這個檔案即可，行情仍是瀏覽器自己去打公開 API。

瀏覽器會直接打公開 API。幣安現貨若被地區限制擋住，頁面會依序改接 OKX、Gate.io，報價最後才用 CoinGecko。合約數據若幣安合約失敗，改接 OKX、Bitget 或 Gate.io。每張卡片都會寫來源。

## 分數怎麼算

總分範圍是 −100 到 +100。數字越高越偏多，越低越偏空。

判定門檻：

| 總分 | 判定 |
| --- | --- |
| ≥ 60 | 強烈多頭 |
| ≥ 15 且 < 60 | 偏多 |
| > −15 且 < 15 | 中性 |
| ≤ −15 且 > −60 | 偏空 |
| ≤ −60 | 強烈空頭 |

15 分圖與 1 小時圖只供看盤，不進入總分。

### 時間週期

趨勢看較大的週期，所以權重不是平均分：

| 週期 | 權重 |
| --- | --- |
| 週線 | 45% |
| 日線 | 35% |
| 四小時 | 20% |

若某個週期的 K 線沒取到，剩下的週期會把權重重新補滿到 100%，頁面上會註明。

### 每個週期裡的指標

每個指標先各自打 −100 到 +100，再乘上權重。某個指標算不出來時，該週期其餘指標也會重新加權。

| 指標 | 權重 | 怎麼給分 |
| --- | --- | --- |
| 均線排列 | 22% | EMA20、EMA50、EMA200。完整多頭排列且價格在 EMA20 之上是 +100；完整空頭排列且價格在 EMA20 之下是 −100。只完成一部分時，分數降到 +75、+45、+20 或對稱的負分。三線幾乎黏在一起則是 0。 |
| 價格對 EMA200 | 16% | 距離 EMA200 的百分比。差 8% 就是滿分 ±100，中間按比例，超過 8% 就停在 ±100。 |
| MACD | 18% | 參數 12、26、9。零軸之上、柱狀體為正且繼續放大是 +100；零軸之下、柱狀體為負且繼續放大是 −100。柱狀體縮短，或剛翻正但還在零軸另一側，分數會降一檔。 |
| RSI | 12% | 14 期。把 50 當 0 分、70 當 +100、30 當 −100，超出就停在邊界。這裡把 RSI 當趨勢動能：超買仍算偏多，超賣仍算偏空，不會自動反向。 |
| ADX / DMI | 16% | 14 期。ADX 低於 15 視為盤整，給 0 分。ADX 越高、+DI 與 −DI 差越多，分數越大；由 +DI、−DI 誰高決定正負。 |
| 布林位置 | 8% | 20 期、2 倍標準差。%B 0.5 是 0 分，1 是 +100，0 是 −100。帶寬很窄時會註明波動收斂。 |
| 量能 | 8% | 近 5 根均量除以前 20 根均量，再配上這 5 根的漲跌。價漲量增往正分，價跌量增往負分。量能萎縮時分數接近 0，不硬給方向。 |

週期分數等於指標分數乘上有效權重後的加總。總分再把三個週期加起來。畫面上每一列都有該指標的分數、權重、貢獻與一句原因，可以把總分加回去。

計算沿用 Wilder 平滑與一般圖表軟體的 EMA 種子（先用簡單平均）。和別的平台可能差一根 K 線或一個小數點，方向不應該相反。

### 支撐與壓力

日線用左右各約 5 根與 3 根確認擺動高點、低點，四小時用更寬的窗口。距離 0.8% 以內的點會併成同一區，並標出最近一次碰到的日期。現價上方的擺動高點當壓力，下方的擺動低點當支撐，各取最近的三個。另外會納入近 30 日的最高與最低，避免最新的極端還沒被確認時整段空白。

## 長線策略參考訊號

頁面上的「長線策略參考訊號」把 BTC/USDT 四小時 K 線當成一套固定規則重播，顯示理論上的多空狀態。它不是交易所委託，也不是投資建議。這套規則的樣本外測試是 −1.2R。提供規則的機器人目前只管理已經有的部位，不會新開比特幣倉位。

只使用已經收盤的四小時 K 線。四小時 K 線對齊 UTC 的 00、04、08、12、16、20（台北時間 08、12、16、20、00、04）。最後一根還沒走完的 K 線會先拿掉，不拿它的收盤來判斷。若上一根收盤已經排定進場或反手，而下一根已經開盤，成交價用那根的開盤價；那根的最高價、最低價和收盤不參與判斷。K 線預設向幣安要 1000 根，失敗才改 OKX、Gate.io，面板上會寫來源。

指標：

- 唐奇安通道 N = 40。通道高是前 40 根最高價，通道低是前 40 根最低價，都不含當根。
- ATR 14，Wilder。真實波幅是高減低、高與前收之差、低與前收之差的最大值。第一個 ATR 是前 14 個真實波幅的簡單平均，之後是（前一個 ATR × 13 + 這根真實波幅）/ 14。
- 倍數 m = 3。

進出場，都在四小時收盤時判斷：

- 空手，而且收盤高於通道高，就在下一根開盤做多。收盤低於通道低，就在下一根開盤做空。兩個方向都會做，但只有空手才進新單。
- 初始停損是進場價減或加 3 倍 ATR。做多減、做空加，ATR 用發出訊號那一根。
- 持倉之後，每一根收盤更新極值。做多取進場以來的最高價（從進場價起算，含剛剛收盤的這根），做空取最低價。新停損是極值減或加 3 倍這根的 ATR。停損只往有利的方向移：做多只上移，做空只下移。
- 停損出場：做多時，任何一根的最低價小於或等於停損就出場，成交在停損價；若開盤已經穿過停損，成交在開盤價。做空則看最高價。沒有固定停利。
- 反向突破：持有多單時，若收盤低於前 40 根最低價，下一根開盤平多並反手做空。持有空單則相反。

重播每一根的順序是：先更新極值與停損並檢查反手，再在空手時檢查進場，最後用更新後的停損檢查這根 K 線的高低點有沒有碰到。理論部位就是把拿到的歷史這樣跑完之後的結果。

實盤濾網預設關閉，只是一行說明。打開之後，它只標示「剛收盤那一根」產生的訊號，較早的理論部位不會被當成一筆新的進場；若現價已經沿突破方向離開觸發價超過 0.5 倍 ATR，它會標成略過。濾網不改變畫面上的理論部位，頁面也不計算部位大小。

## 資料來源

全部都不需要 API 金鑰，由瀏覽器直接讀取。

- 現貨報價與 K 線：幣安 `data-api.binance.vision`，失敗再試 `api.binance.com`、OKX、Gate.io。報價最後備援是 CoinGecko。
- 即時價格：`wss://data-stream.binance.vision` 的 `btcusdt@miniTicker`。連不上就跟著 60 秒輪詢。
- 約合台幣：CoinGecko。
- 永續資金費率、未平倉量：幣安 U 本位，失敗改 OKX、Bitget、Gate.io。
- 多空比：幣安合約帳戶比，失敗改 Bitget，再改 Gate.io 的多空帳戶數。這是該交易所的帳戶比例，不是全市場保證金。
- 恐懼與貪婪指數：[Alternative.me](https://alternative.me/crypto/fear-and-greed-index/)。
- 比特幣占比與加密貨幣總市值：CoinGecko global。

某一項失敗時，那一張卡片會顯示取不到，其他區塊繼續用上一筆成功的資料或維持空白，不會把整頁打掉。若 60 秒那次整頁更新失敗，畫面留著上一筆，並標明這次沒更新成功。
